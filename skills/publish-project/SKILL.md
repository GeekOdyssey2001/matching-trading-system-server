# 提交和推送项目

1. 检查工作目录、Git 状态、当前分支、远程地址及待提交内容；项目未初始化时先确认远程历史，避免覆盖已有内容。
2. 本项目默认远程仓库为 `https://github.com/GeekOdyssey2001/matching-trading-system-server.git`。以用户最新指定的地址为准；不要覆盖不同的现有远程配置。
3. 检查 `.gitignore`、敏感信息、机器专用配置和构建产物，根据本次请求确定提交范围，并运行适合改动的检查。
4. 整理需要提交的文件，提交前查看暂存内容，使用反映实际更改的提交信息。
5. 用户明确要求推送时，将提交推送到对应远程分支；若远程已有历史，先获取并检查，保留已有历史，不强制推送。
6. 核对提交和远程分支状态，报告提交号、分支、检查结果及任何未完成事项。遇到认证、网络或权限限制时报告实际错误，不擅自更改凭据或代理设置。
